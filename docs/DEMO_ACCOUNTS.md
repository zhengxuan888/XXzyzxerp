# 本地演示账号

这些账号只用于本地 V2 演示数据库，不代表生产账号，也不应部署到预发布或生产环境。

| 账号 | 角色 | 体验重点 | 密码 |
| --- | --- | --- | --- |
| `founder` | 平台管理员 | 全局配置、组织、权限与审计 | `SEED_FOUNDER_PASSWORD`，未配置时为 `123456` |
| `demo_manager` | 业务板块负责人 | 当前业务板块内的员工、订单、发货、物流和审批 | `SEED_DEMO_PASSWORD`，未配置时为 `123456` |
| `测试员工_中文` | 普通员工（受限） | 登录、个人范围和无权操作时的 403 行为 | 与 `SEED_FOUNDER_PASSWORD` 相同 |
| `demo_sales` | 销售录单员 | 手工录单、上传沟通凭证、提交核单 | `123456` |
| `demo_reviewer` | 核单员 | 核单通过、退回和审批 | `123456` |
| `demo_shipping` | 发货员 | 待发货、物流模板和出货凭证 | `123456` |
| `demo_after_sales` | 物流售后员 | 轨迹、异常待办、备注和标签 | `123456` |
| `demo_finance` | 财务员 | 费用和审批查看 | `123456` |
| `demo_hr` | 人事员 | 员工、考勤、请假和公告 | `123456` |

## 使用方法

在 V2 项目目录执行 `pnpm db:seed` 后，打开本地登录页：

`http://127.0.0.1:3000/login`

如果在 `.env` 中设置了 `SEED_FOUNDER_PASSWORD` 或 `SEED_DEMO_PASSWORD`，以环境变量为准。`123456` 仅用于本地演示，验收后应删除这些账号或重新设置强密码，禁止用于预发布或生产环境。
