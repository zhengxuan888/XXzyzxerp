# 投放运营工作台

## 目的

本模块把旧系统的投流日报、KPI 看板和素材管理整理为一个可配置、可审计、按组织隔离的运营模块。它不是某个固定平台的页面：渠道、来源、指标、素材状态、标签、工作台卡片和适用对象都由数据库配置。

## 员工日常操作

1. 在“投放日报”选择日期与已授权的数据来源，填写花费、展示、点击、转化等原始事实。
2. 保存草稿或提交审核。退回后只修改自己的退回日报；锁定后的日报不能被普通员工改写。
3. 在“素材中心”新增、筛选、归档素材，并把微信截图、图片、视频或 PDF 拖入附件区。文件预览仍按附件权限校验。
4. 在“我的投放工作台”查看自己被允许看到的待办、指标和快捷入口。

## 主管与管理员操作

1. 主管可按被授权的团队范围查看日报、审核、退回并锁定已确认的日报。
2. KPI 可按业务板块、部门或单个 Membership 设置；实际值只汇总已提交/锁定的日报原始数据，再计算 ROAS、CPA 等比例，避免把员工日报中的比例直接平均。
3. 有配置权限的人可以管理数据来源、指标、素材状态、标签和工作台卡片。卡片可以配置显示位置、顺序、指标/待办/系统内跳转和适用角色、部门、员工。

## 权限与数据边界

- 所有读取和写入都由服务端检查 `Membership + Action + Scope`；工作台卡片或前端按钮只决定展示，不能扩大数据范围。
- 日报、KPI、素材、来源和附件均记录公司/业务板块/部门/站点/员工归属（适用时）。
- 主管仅能查看和管理其配置的部门树/下属范围；业务板块级 KPI 需要显式的业务板块或全局 Scope。
- 修改日报状态、KPI、来源、指标、素材、归档和工作台配置都会写入 Audit Log。
- Access Grant 过期或撤销后，服务端权限会同时失效；菜单或卡片可见性不是授权依据。

## 指标与金额规则

- 金额以最小货币单位保存；界面以货币格式展示，避免 JavaScript 浮点误差。
- 员工只能填写直接录入指标。比例指标只能引用当前业务板块的启用原始指标，由系统计算。
- 比例公式不能自引用、不能引用派生指标，防止循环或错误口径。
- 多币种不自动合并；需要按币种分别查看，或由后续经过批准的汇率模块转换。

## 当前范围与后续扩展

已覆盖：日报、审核、KPI、素材库、附件、来源/指标/标签/状态配置、工作台卡片配置。

未接入任何真实广告账户、Facebook、WhatsApp、微信、Lark 或第三方 API。未来适配器应以新的数据来源配置接入，不得在权限逻辑中写死渠道或部门。

## 验收重点

1. 员工只能新建、查看和提交自身范围的日报。
2. 主管审核范围外的日报必须被拒绝。
3. 退回、锁定后的日报状态变化在列表、工作台和审计中一致。
4. KPI 的团队 ROAS/CPA 必须先汇总原始值再计算。
5. 素材“全部/未归档/已归档”、分页、数据源和标签筛选均由服务端执行。
6. 没有附件读取权限时，不返回或预览素材文件信息。
