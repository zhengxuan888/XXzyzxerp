# 员工汇报线与逐级数据权限

## 规则

- 员工：默认只查看本人数据。
- 经理：查看直属员工以及这些员工继续向下的全部下属。
- 总监：查看直属经理、经理团队及其全部下属。
- 更高层级：沿 Membership 汇报线继续递归，不依赖“经理”“总监”等角色名称。
- 同级、无汇报关系人员、其他业务板块默认不可见，额外范围必须通过独立授权配置。

## 配置

“岗位与归属”页面增加“设置直属上级”工作区。拥有 `membership.reporting_line.manage` 动作权限的人员可以调整汇报关系。

服务端强制验证：

- 上级和员工必须在同一业务板块。
- 禁止自己成为自己的上级。
- 禁止形成任何直接或间接循环。
- 修改写入 Audit Log，并立即影响统计、目标及所有使用 `SUBORDINATES` Scope 的业务接口。

## 测试证据

权限测试已覆盖：

- 经理访问直属员工：允许。
- 上级访问隔级下属：允许。
- 经理访问同级人员：拒绝。
- Lint、TypeScript、55 项测试和 production build：通过。
