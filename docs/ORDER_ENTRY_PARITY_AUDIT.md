# 订单录入逐项对照审计

更新时间：2026-07-26

本清单以旧 ERP `src/app/(dashboard)/order-entry/page.tsx` 和对应订单 API 为事实基线，V2 未经逐项验证不得标记为完成。

| 功能 | 旧 ERP 证据 | V2 当前状态 | 门禁 |
|---|---|---|---|
| 手工录入 | 表单字段与即时校验 | 已有 | 必须保留手工输入 |
| 订单号 | 录单页显示并由服务端保存 | 已显示“保存后自动生成”，服务端生成真实值 | 不接受前端伪造 |
| 店铺 ID | 必填 | 已有 | 模板可配置 |
| 物流渠道 | 可手填 | 已有 | 不得改成固定选项 |
| 商品名/ SKU | 商品名可手填，SKU 可检索 | 已有 | 两种方式都保留 |
| 收件信息 | 姓名、电话、国家、州/县、城市、地址、邮编 | 已有 | 必填由模板决定 |
| 客户邮箱 | 必填并可验证 | 已有 | 未验证不能伪造通过 |
| 客户/员工 WhatsApp | 两个字段 | 已有 | 权限控制显示 |
| COD 金额 | 金额输入 | 已有 | 金额使用整数分/Decimal |
| COD 币种 | EUR/CNY/USD/GBP/PLN/CZK/HUF/RON/BGN/SEK/DKK/NOK/CHF | 已恢复下拉 | 选项不得丢失 |
| 付款方式 | 到付/预付 | 已恢复单选 | 模板可设置默认值 |
| 运费/重量/备注 | 旧版字段 | 已有 | 不得隐藏 |
| 截图上传与预览 | 录单页直接上传、预览、删除 | V2 当前在订单创建后详情页附件面板 | 需恢复录单流程内的明确上传闭环 |
| Excel 批量导入 | 旧版支持上传、解析、逐行校验 | 已完成标准模板下载、智能列名识别、逐行预览、整批事务写入和审计 | 必须先预览再导入；任何错误阻止整批写入 |
| 智能文本/地址 | 旧版有辅助识别 | V2 已有地址辅助识别 | 仅辅助，不跳过人工核对 |
| 当日订单搜索/删除 | 旧版支持 | V2 需单独回归确认 | 删除必须受权限和状态限制 |

## 当前禁止事项

- 不得把客户改成强制固定客户选择。
- 不得删除手填商品名、店铺 ID、物流渠道、COD 币种、WhatsApp 或截图凭证。
- 不得把“回填运单号”直接等同于“确认发货”。
- 不得以 UI 隐藏代替后端权限校验。

## 下一步验收顺序

1. 恢复录单页直接上传/预览客户沟通凭证的完整闭环。
2. 已实现 Excel 标准模板下载、上传预览、逐行错误和确认导入；后续新增外部来源模板时继续通过列名映射配置扩展，不改变订单写入规则。
3. 对订单列表搜索、分页、删除和权限做回归测试。
4. 用旧版字段清单逐项截图验收后，再进入物流页面对照。
