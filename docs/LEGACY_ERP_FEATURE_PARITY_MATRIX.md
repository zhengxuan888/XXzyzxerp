# 旧 ERP 功能对照与 V2 合并原则

> 状态：持续更新。旧 ERP 的可用能力默认保留；重复入口允许合并，业务能力、数据和权限动作不得因此消失。

## 1. 信息架构原则

- “我的工作台”只展示当前岗位每天需要处理的统计、待办和快捷入口。
- “统计报表”承载日期、部门、员工、团队范围及趋势、分布、排行等深入分析。
- 旧版“我的统计”并入上述两层，避免维护重复页面。
- 统计组件的名称、顺序、位置、启停、目标链接、可见动作和数据范围由数据库配置。
- 角色名称不参与代码判断。角色权限、个人额外授权和有效期共同决定组件是否可见。
- 所有统计必须经过服务端组织范围过滤；前端隐藏卡片不等于权限控制。

## 2. 已确认的统计能力

| 旧版能力 | V2 归属 | 保留方式 |
| --- | --- | --- |
| 今日开单、昨日开单、昨日发货 | 我的工作台 / 销售统计 | 角色统计组件 |
| 总订单、本月订单、平均 COD、覆盖国家 | 统计报表 / 订单统计 | 时间与组织范围筛选 |
| 订单国家分布 | 统计报表 / 订单统计 | 图表组件 |
| 在职、出勤、迟到、缺勤、请假 | 人事工作台 / 考勤统计 | 人事动作与部门范围控制 |
| 期间订单、订单金额、出勤率、日均开单 | 统计报表 / 总览 | 可配置指标卡 |
| 考勤趋势、订单趋势、状态分布、员工排行 | 统计报表 | 分页、筛选、导出 |
| 待填单号、运输中、派送中、已送达、未处理 | 物流售后工作台 | 可点击队列卡 |
| 地址错误、派送失败、到达代取、拆包拒收等 | 物流售后工作台 | 可配置异常队列卡 |

## 3. 功能模块归类

| 模块 | 新版归属 | 当前决策 |
| --- | --- | --- |
| 订单录入、核单、订单管理 | 销售与订单 | 保留并优化单页流程 |
| 待发货、运单回填、确认发货 | 物流与售后 | 回填运单号不等于发货 |
| 物流追踪、逐轨迹备注/标签 | 物流与售后 | 默认显示最新轨迹，可展开全部 |
| 物流回款、COD 账单、运费账单、对账 | 财务 | 菜单归财务，物流仅提供来源数据 |
| SKU、库存、商品上架、上品 | 商品与库存 | 保留并拆分动作权限 |
| 员工、考勤、请假、面试、加班 | 人事与行政 | 保留，按部门与额外授权过滤 |
| 任务、今日目标、工作记录 | 员工运营 | 保留，工作台只显示相关摘要 |
| KPI、投流日报、素材 | 投流运营 | 预留独立业务模块与动作权限 |

## 4. SKU 导入要求

- 支持导入、导出和下载标准模板。
- 支持通过工作表名称、表头别名和必填列自动识别不同来源模板。
- 模板、字段映射、默认值和校验规则必须数据库配置，不能为物流商或仓库写代码分支。
- 流程固定为：上传 → 自动识别 → 预检查 → 展示新增/更新/错误 → 人工确认 → 幂等导入 → 审计。
- 无法可靠识别时必须等待人工选择映射，禁止猜测后直接写库。
- 校验 SKU 唯一性、仓库/库位、数量、金额单位、重复行和负库存风险。
- 权限拆分为 `sku.import` 与 `sku.export`，可通过角色模板或员工额外授权开启。

## 5. 待逐项核验

- 回收站的保留期限、恢复范围及删除审批。
- COD 回款账单与物流运费账单的实际导入模板和对账规则。
- 商品上架、上品管理与 SKU 主数据的边界。
- 任务、今日目标、日报之间可合并的数据与必须独立保留的动作。
- 投流日报、KPI、素材管理所需的组织范围和金额口径。
