# 工作台与按钮体系更新（2026-07-29）

## 本轮完成

- 今日目标页增加显眼的“我的今日目标”填写入口，员工无需在列表中寻找自己。
- 增加独立的团队目标：支持业务板块或部门维度配置订单数、金额、币种和说明。
- 团队目标同时展示个人目标合计、未分配缺口、实际完成量和完成率。
- 团队目标由 `team_goal.read`、`team_goal.manage` 动作控制，服务端按 Membership 与组织范围校验。
- 首页快捷入口读取数据库菜单元数据，并根据当前 Membership 的有效菜单权限动态显示和排序。
- 菜单的 `requiredCondition.dashboardShortcut` 和 `shortcutOrder` 可决定是否出现在快捷入口及显示位置，不依赖角色名称。
- 统一按钮为白底金色设计体系，补充主要、次要、轮廓、幽灵、成功、警告、危险及图标尺寸。

## 权限与审计

- 普通员工可填写自己的个人目标。
- 有下属范围权限的管理者可在授权范围内查看或调整个人目标。
- 团队目标管理需单独动作权限，不因角色名称自动开放。
- 团队目标写入后记录 Audit Log。
- 公司、业务板块、部门、角色名称均未写入权限判断。
