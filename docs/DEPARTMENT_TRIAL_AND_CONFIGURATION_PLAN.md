# 部门试用与配置计划

## 原则

- 先完成销售履约闭环，再按财务、行政、人事顺序组织试用。
- 工作台、菜单和可执行动作根据 Membership、Action、Scope 和有效授权动态生成，不按角色名或部门名写死。
- 旧 ERP 功能作为对照清单；保留有价值的业务能力，不复制旧权限漏洞、垃圾数据和重复劳动。
- 每轮试用必须记录岗位、操作路径、问题、配置修改、代码修改和验收结果。

## 第一阶段：销售部门

| 岗位能力 | Action | 工作台队列 | 当前目标 |
| --- | --- | --- | --- |
| 录入订单 | `order.create` / `order.submit` | 我的草稿 | 保存、提交核单、库存预占 |
| 核单 | `order.review` | 待核单 | 通过、驳回及原因 |
| 发货 | `order.ship` / `shipment.create` | 待发货 | 原子出库、物流单、开始跟踪 |
| 物流查看 | `shipment.read` | 运输中 | 全生命周期轨迹 |
| 跟单售后 | `shipment.track.update` | 今日跟进、异常件 | 备注、责任人、下次跟进 |

## 后续部门试用

### 财务

- COD 应收、回款批次与对账。
- 费用申请、预算、付款、发票和审批。
- 金额、币种、差异、作废和冲正。
- 财务字段权限、导出权限和审计。

### 行政

- 公告、文档、考勤、请假和基础审批。
- 员工入职、启停、部门调整和资料完整性。
- 公告可见范围、文档版本和确认回执。

### 人事

- 员工与 Membership 生命周期。
- 考勤异常、请假审批、岗位变更。
- 薪资和提成属于高敏感后续模块，未单独授权前不导入旧数据。

## 每个部门可配置项

1. 工作台模块开关、排序和快捷入口。
2. 菜单、子菜单与 Action 映射。
3. 默认筛选、默认排序和分页大小。
4. 字段可见、字段可编辑和脱敏策略。
5. 数据 Scope：本人、部门、站点、业务板块或单独授权。
6. 模板字段、默认值、必填条件和校验规则。
7. 待办阈值、超时提醒、升级规则和通知对象。
8. 批量操作、导入、导出和打印权限。
9. 审批步骤、审批条件和转授权规则。
10. 空状态、错误状态、撤销和回滚策略。
