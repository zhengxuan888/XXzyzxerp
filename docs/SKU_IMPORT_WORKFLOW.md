# 商品与 SKU 智能导入/导出

## 适用范围

本模块用于将商品和 SKU 主数据导入当前业务板块，或导出当前业务板块的商品/SKU 台账。它不绑定供应商、仓库、国家或业务板块名称。

## 使用流程

1. 有 `product.import` 动作的人员下载标准模板，或上传来自腾讯文档等来源的 XLSX/CSV 文件。
2. 系统扫描每个工作表的前 24 行，识别通用字段别名及真实表头行；无需把某个合作方名称写进代码。
3. 如果多个工作表匹配度相同，员工必须选择正确的工作表和表头行并重新预览；系统不会猜测写入。
4. 预览显示逐行结果：新增商品、新增 SKU、已存在跳过或拒绝原因。
5. 所有拒绝行修正后才能确认导入。确认时再次读取、校验当前数据库和事务写入；冲突时整批回滚，不产生半批数据。

## 数据保护规则

- `.xlsx` 不只看扩展名，还会检查 ZIP 工作簿签名；CSV/XLSX 最大 10MB、最多 1000 行。
- 商品编码和商品名称为必填；同一商品编码的名称、分类、单位或描述不一致会被拒绝。
- 同一商品可占多行以导入多个 SKU；同一商品内的重复 SKU 会被拒绝。
- 已存在的商品/SKU只会明确标记为跳过或新增 SKU，不会静默覆盖商品名称、条码或其他主数据。
- 每次确认导入都会记录文件 SHA-256、所选工作表、表头行、识别字段、写入数量和操作者审计。
- 导出需要独立的 `product.export` 动作；导出仅包含当前 Membership 有效业务上下文的数据。

## 支持的字段别名

标准字段为：商品编码、商品名称、分类、单位、SKU编码、条形码、商品描述。

系统同时识别常见的中英文通用别名，例如“产品编号 / Item Code”“产品名称 / Item Name”“SKU / SKU No”。无法识别的表头不会自动映射；员工需改用标准模板或选择正确的表头。

## 当前边界

- 旧式 `.xls` / `.xlt` 文件不直接解析，需先另存为 `.xlsx` 或 `.csv`；不能伪装为支持。
- 本轮导入的是商品/SKU主数据，不会直接覆盖库存余额。库存期初和调整需要独立、可追溯的库存导入流程。
- 用户可使用标准模板或自动识别不同来源模板；后续如需将某个外部格式长期固化为可维护 Profile，可在不改业务代码的前提下增加数据库模板配置。
