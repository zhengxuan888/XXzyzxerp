## 安全控制

- 隔离库名称由 UTC 时间戳生成，不接受前端或业务输入。
- 仅备份本地 `erp_v2`，不会覆盖或写入源库。
- `pg_restore` 使用 `--exit-on-error --no-owner --no-acl`。
- 对 public schema 全部表逐表比对源库和恢复库行数。
- 比对有效附件的 `storageKey`、字节数和 SHA-256。
- 无论成功或失败，脚本只清理自己创建的隔离库和临时备份。
- 输出不包含密码、Token、完整业务数据或附件内容。

## 尚需预发布环境验证

- 备份加密、异地保管、访问控制和自动过期。

- 真实数据规模下的 RTO/RPO。

- 由创始人确认最终 RTO、RPO、保留期和恢复负责人。
