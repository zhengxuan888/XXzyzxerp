## 首批建议

1. 26名启用员工中，先由负责人勾选实际在职人员。
2. 84个SKU由仓库/商品负责人确认是否仍在销售，库存重新盘点。
3. 从订单中只选择仍需发货、运输、派送、异常处理或退回跟踪的记录。
4. 随这些订单带走必要客户、物流轨迹、84条人工备注中的相关部分和可验证图片。
5. 财务另行决定COD批次和明细，不与首批业务数据混合决定。

## 保留依赖规则

- 保留订单 → 必须同时选择必要客户、商品/SKU、录单员工映射。
- 保留物流 → 必须先保留订单，并建立承运商/渠道映射。
- 保留备注 → 必须保留对应订单和可匹配的轨迹事件。
- 保留图片 → 必须验证文件存在、类型、大小、校验和和订单归属。
- 保留COD明细 → 必须保留批次，并完成订单号、币种、金额对账。
- 保留考勤/薪资 → 必须先确认员工身份映射，并获得人事/财务授权。
